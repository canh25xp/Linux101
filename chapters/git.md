# Version control with `git`

## Prerequisite

Since `git` is such a popular if not the most well known **version control** system,
I will presumed that you know at least these `git` basic commands:

- `git init`
- `git clone`
- `git add`
- `git commit`
- `git pull`
- `git push`

## Contents

This chapter will provide some common tasks and workflows that you might need to use in your day to day life.
